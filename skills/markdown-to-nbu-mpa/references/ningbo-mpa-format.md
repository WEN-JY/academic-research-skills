# 宁波大学 MPA 格式摘要

本文件根据仓库根目录的 `宁波大学格式要求.md` 提炼，仅保留当前 skill 需要用到的可执行规则。

## 1. 文档结构

宁波大学研究生学位论文通常包含：

1. 封面
2. 英文封面
3. 独创性声明及授权声明
4. 中英文摘要及关键词
5. 符号说明
6. 目录
7. 正文
8. 参考文献
9. 附录及附表
10. 在学研究成果
11. 致谢

本 skill 自动化重点在第 4、6、7、8、9、10、11 部分。

## 2. 通用版式

- A4 双面
- 上边距 `2.5cm`
- 下边距 `2.5cm`
- 左边距 `3cm`
- 右边距 `2cm`
- 正文中文宋体
- 西文 `Times New Roman`
- 字符间距标准
- 正文 `1.3` 倍行距
- 各章之间用分页符分页

## 3. 摘要与关键词

- 中文摘要标题：三号黑体、居中
- “摘要”二字：小三号黑体、居中
- 摘要正文：小四号宋体、首行缩进 2 字符、两端对齐、`1.3` 倍行距
- 中文关键词：`3–8` 个，行首缩进 2 字符，关键词之间用全角逗号
- 英文摘要正文：小四号，`1.3` 倍行距
- 英文关键词之间用半角逗号

## 4. 正文标题体系

- 引言：另起一页，居中，小三号黑体
- 章标题：另起一页，顶格，小三号黑体
- 节标题：顶格，四号黑体
- 小节标题：顶格，小四号黑体
- 编号推荐统一为：
  - `# 第1章 XXX`
  - `## 1.1 XXX`
  - `### 1.1.1 XXX`

说明：
学校文件同时允许人文社科类论文采用“章、节”体系。当前 skill 为了兼容现有自动化脚本，默认采用 `第N章 + 1.1 + 1.1.1` 的混合写法。

## 5. 图表公式

- 图题置于图下，居中，编号按章编排，如 `图2.3`
- 表题置于表上，居中，编号按章编排，如 `表2.1`
- 图片默认按上下环绕处理，宽度为版心 100%，图片与图题之间不保留额外空行
- 表格采用三线表，内竖线使用虚线
- 公式单独成行，编号置于右端
- 学校文件允许全文连续编号或分章编号
- 当前 skill 默认采用分章编号 `（章-序）`

## 6. 参考文献

- 标题“参考文献”：居中，小三号，黑体
- 文内引用以上标 `[1]` 标示
- 文后参考文献按文中首次出现顺序排列
- 参考文献著录遵循 `GB/T 7714-2015`

- 奇偶页不同页眉
- 摘要部分罗马页码与正文部分阿拉伯页码的分节切换
- 目录域自动更新
- “在学研究成果”条目模板化生成

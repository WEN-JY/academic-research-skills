# 从 `项目风险管理研究.docx` 提取的版式规则

本文档记录从 `项目风险管理研究.docx` 直接提取出的版式特征，用于补充 `docx-thesis-format` 的规则配置与检测逻辑。

## 页面与分节

- 页面大小：A4 纵向
  - 宽：`11907 twips` ≈ `21.00 cm`
  - 高：`16840 twips` ≈ `29.70 cm`
- 文档共识别 `11` 个分节。
- 前置部分多个分节设置了 `titlePg`。
- 前置部分使用罗马数字页码，正文部分切回阿拉伯数字页码。

3. Abstract
4. 图目录
5. 表目录
6. 中英文对照及缩略表


说明：

- 目录使用 Word 自动目录域，不建议脚本直接重排页码。
- 脚本应检测目录域是否存在，并检测目录项顺序是否符合模板。

## 页码

- 前置部分：`upperRoman`
- 前置页码起始值：`1`
- 正文部分：默认阿拉伯数字页码
- 页码位于页脚
- 样本文档页脚页码使用了 `PAGE` 域

## 页眉

- 统一前缀：`浙江大学硕士学位论文`
- 页眉段落：两端对齐

- 封面类分节是否都允许 `0` 边距

- 参考文献页眉标题前是否固定保留双空格
